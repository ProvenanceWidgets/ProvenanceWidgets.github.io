ProvenanceWidgets is a JavaScript library that tracks the recency and frequency of user interactions with individual UI controls and dynamically overlays this provenance onto them. Version 2.x integrates SuperProvenanceWidgets, an extension to ProvenanceWidgets featuring a SuperWidget that tracks and visualizes provenance across multiple UI controls.

## Getting Started

### What you'll need

- [Node.js](https://nodejs.org/en/download/) 20.19+ or 22.12+, and npm 10.0+.

## Quick Start

Choose a starter project:

<Tabs groupId='framework'>
  <TabItem value='react' label='React'>
    ```bash
    git clone --branch v2 https://github.com/ProvenanceWidgets/provenance-widgets-starter.git
    cd provenance-widgets-starter
    ```
  </TabItem>
  <TabItem value='web-components' label='Web Components'>
    ```bash
    git clone --branch v2 https://github.com/ProvenanceWidgets/provenance-widgets-vanilla-starter.git
    cd provenance-widgets-vanilla-starter
    ```
  </TabItem>
</Tabs>

Finally, install ProvenanceWidgets 2.x and the remaining dependencies, then start the development server:

```bash
npm install provenance-widgets@^2.0.0
npm run dev
```

## Manual Setup

### Installation

Install ProvenanceWidgets from npm:

```bash
npm install provenance-widgets
```

### Configuration

<Tabs groupId='framework'>
  <TabItem value='react' label='React'>
    ProvenanceWidgets builds on PrimeReact components. Add the following to your project's entry file to apply PrimeReact's styles:

    ```jsx
    // ProvenanceWidgets relies on a PrimeReact theme for styling.
    import "primereact/resources/themes/lara-light-cyan/theme.css";
    ```

    Then, import ProvenanceProvider in your application's entry file. It provides the shared registry used by the Aggregate and Temporal provenance views:

    ```jsx {2,8-11} showLineNumbers
    import { createRoot } from "react-dom/client";
    import { ProvenanceProvider } from "provenance-widgets";

    // Your application imports here
    import App from "./App.jsx";

    createRoot(document.getElementById("root")).render(
      <ProvenanceProvider>
        {/* All ProvenanceWidgets controls in this tree share one provenance registry. */}
        <App />
      </ProvenanceProvider>,
    );
    ```
  </TabItem>
  <TabItem value='web-components' label='Web Components'>
    Add the following to your application's entry file to register the ProvenanceWidgets Web Components and load their styles:

    ```js
    import "provenance-widgets/web-components";
    import "provenance-widgets/web-components/styles.css";
    ```
  </TabItem>
</Tabs>
