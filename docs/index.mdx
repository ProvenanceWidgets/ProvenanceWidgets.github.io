SuperProvenanceWidgets (SW) is the React-based second generation of ProvenanceWidgets, a JavaScript library of UI control elements that track and dynamically overlay a user's analytic provenance ***in situ*** and ***out of the box***. SW preserves the frequency and recency overlays introduced by PW and extends them with Aggregate and Temporal views, including a shared provenance view that connects the interaction histories of multiple controls in one interface.

## Getting Started

### What you'll need

- [Node.js](https://nodejs.org/en/download/) 20.19+ or 22.12+, and npm 10.0+.

## Quick Start

For getting started quickly, clone one of our starter code repositories:

<Tabs groupId='framework'>
  <TabItem value='react' label='React'>
    ```bash
    npm create vite@latest provenance-widgets-starter -- --template react
    ```
  </TabItem>
  <TabItem value='web-components' label='Web Components'>
    ```bash
    npm create vite@latest provenance-widgets-vanilla-starter -- --template vanilla
    ```
  </TabItem>
</Tabs>

Then, navigate to the project directory:

<Tabs groupId='framework'>
  <TabItem value='react' label='React'>
    ```bash
    cd provenance-widgets-starter
    ```
  </TabItem>
  <TabItem value='web-components' label='Web Components'>
    ```bash
    cd provenance-widgets-vanilla-starter
    ```
  </TabItem>
</Tabs>

Finally, install SW and its peer dependencies and start the development server:

```bash
npm install provenance-widgets@2 react@^19.2 react-dom@^19.2 preact@^10.29
npm run dev
```

## Manual Setup

### Installation

```bash
npm install provenance-widgets@2
```

### Configuration

<Tabs groupId='framework'>
  <TabItem value='react' label='React'>
    SW builds on PrimeReact components. Add the following to your project's entry file to apply PrimeReact's styles:

    ```jsx
    // SW relies on a PrimeReact theme for styling.
    import "primereact/resources/themes/lara-light-cyan/theme.css";
    ```

    Then, import ProvenanceProvider in your application's entry file. It provides the shared registry used by SW's Aggregate and Temporal provenance views:

    ```jsx {2,8-11} showLineNumbers
    import { createRoot } from "react-dom/client";
    import { ProvenanceProvider } from "provenance-widgets";

    // Your application imports here
    import App from "./App.jsx";

    createRoot(document.getElementById("root")).render(
      <ProvenanceProvider>
        {/* All SW widgets in this tree share one provenance registry. */}
        <App />
      </ProvenanceProvider>,
    );
    ```
  </TabItem>
  <TabItem value='web-components' label='Web Components'>
    Add the following to your project's `index.html` file to import SW's Web Components and styles:

    ```html {5-6} showLineNumbers
    <!DOCTYPE html>
    <html lang="en">
      <head>
        <!-- Your head tags here -->
        <script type="text/javascript" src="/node_modules/provenance-widgets/dist/web-components/index.js"></script>
        <link rel="stylesheet" href="/node_modules/provenance-widgets/dist/web-components/styles.css" />
      </head>
      <body>
        <!-- Your body here -->
      </body>
    </html>
    ```
  </TabItem>
</Tabs>
