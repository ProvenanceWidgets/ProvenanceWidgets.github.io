# Multiselect

`MultiSelectDropdown` records the complete selected set after every committed change. Provenance stores stable option keys, while `onSelectedChange` returns the resolved option objects in the order defined by `options`.

<Tabs groupId="framework">
  <TabItem value="react" label="React">

```tsx
import { useState } from "react";
import {
  MultiSelectDropdown,
  ProvenanceButton,
} from "provenance-widgets";

const cities = [
  { label: "New York", value: "NY" },
  { label: "Rome", value: "RM" },
  { label: "London", value: "LDN" },
  { label: "Paris", value: "PRS" },
];

export function CityMultiselect() {
  const [selected, setSelected] = useState([cities[0]]);

  return (
    <div>
      <ProvenanceButton target="cities" />
      <MultiSelectDropdown
        id="cities"
        options={cities}
        selected={selected}
        onSelectedChange={setSelected}
        optionLabel="label"
        optionValue="value"
        placeholder="Select cities"
        dataLabel="Cities"
      />
    </div>
  );
}
```

```js
const cities = [
  { label: "New York", value: "NY" },
  { label: "Rome", value: "RM" },
  { label: "London", value: "LDN" },
  { label: "Paris", value: "PRS" },
];

const multiselect = document.querySelector("#cities");
multiselect.options = cities;
multiselect.selected = [cities[0]];
multiselect.optionLabel = "label";
multiselect.optionValue = "value";

multiselect.addEventListener("selectedChange", event => {
  multiselect.selected = event.detail;
});
```

## React properties

| Property | Type | Default | Notes |
| --- | --- | --- | --- |
| `options` | `unknown[]` | `[]` | Available primitive values or option objects. |
| `selected` | `unknown[]` | `[]` | Preferred controlled selection. |
| `value` | `unknown[]` | — | Controlled alias for `selected`. |
| `defaultSelected` / `defaultValue` | `unknown[]` | `[]` | Initial uncontrolled selection. |
| `optionLabel` | `string` | inferred | Field displayed to the user. |
| `optionValue` | `string` | inferred | Field stored as the provenance key. |
| `dataKey` | `string` | inferred | Highest-priority stable key field. |
| `placeholder` | `string` | — | Text shown while the selection is empty. |
| `display` | `string` | PrimeReact default | Controls how selected values are summarized. |
| `onSelectedChange` | `(options, event) => void` | — | Receives the complete resolved selection array. |
| `onChange` | `(options, event) => void` | — | Alias callback with the same array. |
| `multiSelectProps` | `object` | `{}` | Additional props forwarded to PrimeReact MultiSelect. |

## Web Component events

| Event | `event.detail` |
| --- | --- |
| `selectedChange` | Complete selected option array. |
| `provenanceChange` | Latest serialized provenance snapshot. |

The Temporal view follows PW behavior: clicking a position restores every option whose active interval contains that point, not only the row that received the click.
