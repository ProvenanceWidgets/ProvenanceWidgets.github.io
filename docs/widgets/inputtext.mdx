# InputText

`InputText` separates typing from a committed provenance interaction. `onChange` updates the live field value; pressing **Enter** records the current text and calls `onValueChange`.

Repeated identical searches are meaningful: each Enter press creates another Temporal interaction and increases that text's Aggregate frequency.

<Tabs groupId="framework">
  <TabItem value="react" label="React">

```tsx
import { useState } from "react";
import { InputText, ProvenanceButton } from "provenance-widgets";

export function SearchInput() {
  const [query, setQuery] = useState("");

  return (
    <div>
      <ProvenanceButton target="search" />
      <InputText
        id="search"
        value={query}
        onChange={setQuery}
        onValueChange={value => console.log("searched", value)}
        placeholder="Search and press Enter"
        dataLabel="Search"
      />
    </div>
  );
}
```

## React properties

| Property | Type | Default | Notes |
| --- | --- | --- | --- |
| `value` | `string` or object | — | Controlled text. If `field` is set, text is read from that object field. |
| `defaultValue` | `string` or object | `""` | Initial uncontrolled value. |
| `field` | `string` | — | Optional property to read from an object value. |
| `placeholder` | `string` | — | Native input placeholder. |
| `onChange` | `(value, event) => void` | — | Fires while the user types and when history is restored. |
| `onInputChange` | `(value, event) => void` | — | Alias for live input changes. |
| `onValueChange` | `(value, event) => void` | — | Fires when Enter commits the text or history restores a value. |
| `inputProps` | `object` | `{}` | Additional props forwarded to the underlying PrimeReact input. |

When the Aggregate view is open, selecting a previous string commits that value back to the input. Clicking a Temporal point restores that exact historical search and closes the provenance panel cleanly.

## Web Component events

| Event | `event.detail` |
| --- | --- |
| `valueChange` | Text committed by Enter or restored from provenance. |
| `provenanceChange` | Latest serialized provenance snapshot. |
