# InputText

An InputText is a user interface control element that allows users to input text.

```jsx
import { useState } from "react";
import { InputText, ProvenanceButton } from "provenance-widgets";

export default function InputTextExample() {
  const [value, setValue] = useState("");

  const provenanceChange = provenance => {
    console.log(provenance);
  };

  const valueChange = nextValue => {
    console.log(nextValue);
    setValue(nextValue);
  };

  return (
    <div>
      <ProvenanceButton target="jsx-provenance-inputtext" />
      <InputText
        id="jsx-provenance-inputtext"
        value={value}
        freeze={false}
        visualize={true}
        onProvenanceChange={provenanceChange}
        onValueChange={valueChange}
      />
    </div>
  );
}

// Create a new instance of the InputText
const inputtext = document.createElement("web-provenance-inputtext");

// Set the properties
inputtext.id = "webcomponent-provenance-inputtext";
inputtext.value = "";
inputtext.freeze = false;
inputtext.visualize = true;

inputtext.addEventListener("provenanceChange", event => {
  console.log(event.detail);
});

inputtext.addEventListener("valueChange", event => {
  console.log(event.detail);
});

// Append it to the DOM
document.body.appendChild(inputtext);
```

## API

:::warning

ProvenanceWidgets InputText is built with PrimeReact InputText, but defines its own commit and provenance behavior. Typing updates the displayed text; pressing **Enter** commits the value and records provenance.

:::

### Events

In React, use `onValueChange` and `onProvenanceChange`. Web Components use `valueChange` and `provenanceChange`, with emitted values available in `event.detail`.
