# Checkbox

A Checkbox is a user interface control element that allows users to select one or more options from a set of options.

```jsx
import { useState } from "react";
import { CheckboxGroup, ProvenanceButton } from "provenance-widgets";

const data = [
  { label: "New York", value: "New York" },
  { label: "Rome", value: "Rome" },
  { label: "London", value: "London" },
  { label: "Istanbul", value: "Istanbul" },
  { label: "Paris", value: "Paris" },
];

export default function CheckboxExample() {
  const [selected, setSelected] = useState(["New York", "Rome"]);

  const selectedChange = nextSelected => {
    console.log(nextSelected);
    setSelected(nextSelected);
  };

  return (
    <div>
      <ProvenanceButton target="cities" />
      <CheckboxGroup
        id="cities"
        name="cities"
        data={data}
        selected={selected}
        optionLabel="label"
        optionValue="value"
        freeze={false}
        visualize={true}
        onProvenanceChange={console.log}
        onSelectedChange={selectedChange}
      />
    </div>
  );
}
```

const checkbox = document.createElement("web-provenance-checkbox");

  console.log(event.detail);
});

  console.log(event.detail);
});

// Append it to the DOM

### Composed React options

Use children when each option needs custom layout or props. The group still owns the state and provenance.

```tsx
import { Checkbox, CheckboxGroup } from "provenance-widgets";

<CheckboxGroup
  id="ingredients"
  selected={selected}
  onSelectedChange={setSelected}
>
  <Checkbox value="chicken" label="Chicken" />
  <Checkbox value="beef" label="Beef" />
  <Checkbox value="lamb" label="Lamb" />
</CheckboxGroup>
```

## React group properties

| Property | Type | Default | Notes |
| --- | --- | --- | --- |
| `data` / `options` | `unknown[]` | `[]` | Options used for data-driven rendering. |
| `selected` / `value` | `unknown[]` | `[]` | Controlled array of selected option keys. |
| `defaultSelected` / `defaultValue` | `unknown[]` | `[]` | Initial uncontrolled selection. |
| `optionLabel` | `string` | inferred | Field displayed beside each checkbox. |
| `optionValue` / `valueField` | `string` | inferred | Field used as the option and provenance key. |
| `dataKey` | `string` | inferred | Highest-priority stable key field. |
| `name` | `string` | generated | Input group name. |
| `onSelectedChange` | `(keys, event) => void` | — | Receives the complete selected key array. |
| `onChange` | `(keys, event) => void` | — | Alias callback with the same array. |
| `checkboxProps` | `object` | `{}` | Props applied to data-driven checkbox items. |

Every interaction records the full selected key array. Clicking the Temporal history restores all checkboxes active at that point.

## Web Component events

| Event | `event.detail` |
| --- | --- |
| `selectedChange` | Complete selected key array. |
| `provenanceChange` | Latest serialized provenance snapshot. |
