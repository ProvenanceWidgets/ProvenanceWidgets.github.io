# Dropdown

`SingleSelectDropdown` selects one option and stores a stable option key in provenance. Its public callback receives the resolved option object, so controlled applications can keep using their original option data.

<Tabs groupId="framework">
  <TabItem value="react" label="React">

```tsx
import { useState } from "react";
import {
  ProvenanceButton,
  SingleSelectDropdown,
} from "provenance-widgets";

const cities = [
  { label: "New York", value: "NY" },
  { label: "Rome", value: "RM" },
  { label: "London", value: "LDN" },
];

export function CityDropdown() {
  const [city, setCity] = useState(cities[0]);

  return (
    <div>
      <ProvenanceButton target="city" />
      <SingleSelectDropdown
        id="city"
        options={cities}
        selected={city}
        onSelectedChange={setCity}
        optionLabel="label"
        optionValue="value"
        placeholder="Select a city"
        dataLabel="City"
      />
    </div>
  );
}
```

```js
const cities = [
  { label: "New York", value: "NY" },
  { label: "Rome", value: "RM" },
  { label: "London", value: "LDN" },
];

const dropdown = document.querySelector("#city");
dropdown.options = cities;
dropdown.selected = cities[0];
dropdown.optionLabel = "label";
dropdown.optionValue = "value";

dropdown.addEventListener("selectedChange", event => {
  dropdown.selected = event.detail;
});
```

## React properties

| Property | Type | Default | Notes |
| --- | --- | --- | --- |
| `options` | `unknown[]` | `[]` | Available primitive values or option objects. |
| `selected` | `unknown` | — | Preferred controlled selection. |
| `value` | `unknown` | — | Controlled alias for `selected`. |
| `defaultSelected` / `defaultValue` | `unknown` | — | Initial selection for uncontrolled use. |
| `optionLabel` | `string` | inferred | Field displayed to the user. Falls back to `label` or `name`. |
| `optionValue` | `string` | inferred | Field used as the stable provenance key. |
| `dataKey` | `string` | inferred | Highest-priority stable key field. |
| `placeholder` | `string` | — | Text shown while no option is selected. |
| `onSelectedChange` | `(option, event) => void` | — | Receives the resolved option after selection or history restoration. |
| `onChange` | `(option, event) => void` | — | Alias callback invoked with the same resolved option. |
| `dropdownProps` | `object` | `{}` | Additional props forwarded to PrimeReact Dropdown. |

The key inference order is `dataKey`, `optionValue`, `value`, `code`, `id`, then `label`. Set `optionValue` or `dataKey` explicitly when option identity must remain stable across data reloads.

## Web Component events

| Event | `event.detail` |
| --- | --- |
| `selectedChange` | The selected option object or primitive. |
| `provenanceChange` | Latest serialized provenance snapshot. |

Aggregate bars show how often and how recently each option was selected. In Temporal view, selecting a historical interval restores the option active at that position.
