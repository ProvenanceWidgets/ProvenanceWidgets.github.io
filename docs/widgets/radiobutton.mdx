# Radio Button

`RadioGroup` owns one scalar selection and one provenance history for the complete group. It supports both data-driven options and composed `Radiobutton` children.

<Tabs groupId="framework">
  <TabItem value="react" label="React">

```tsx
import { useState } from "react";
import { ProvenanceButton, RadioGroup } from "provenance-widgets";

const toppings = [
  { label: "Cheese", value: "cheese" },
  { label: "Mushroom", value: "mushroom" },
  { label: "Peppers", value: "peppers" },
];

export function ToppingGroup() {
  const [selected, setSelected] = useState("cheese");

  return (
    <div>
      <ProvenanceButton target="topping" />
      <RadioGroup
        id="topping"
        data={toppings}
        selected={selected}
        onSelectedChange={setSelected}
        optionLabel="label"
        optionValue="value"
        dataLabel="Topping"
      />
    </div>
  );
}
```


```js
const radio = document.querySelector("#topping");
radio.data = [
  { label: "Cheese", value: "cheese" },
  { label: "Mushroom", value: "mushroom" },
  { label: "Peppers", value: "peppers" },
];
radio.selected = "cheese";
radio.optionLabel = "label";
radio.optionValue = "value";

radio.addEventListener("selectedChange", event => {
  radio.selected = event.detail;
});
```

## Composed React options

```tsx
import { RadioGroup, Radiobutton } from "provenance-widgets";

<RadioGroup
  id="topping"
  selected={selected}
  onSelectedChange={setSelected}
>
  <Radiobutton value="cheese" displayLabel="Cheese" />
  <Radiobutton value="mushroom" displayLabel="Mushroom" />
  <Radiobutton value="peppers" displayLabel="Peppers" />
</RadioGroup>
```

## React group properties

RadioGroup also accepts all [common provenance properties](../index.mdx#common-provenance-properties).

| Property | Type | Default | Notes |
| --- | --- | --- | --- |
| `data` / `options` | `unknown[]` | `[]` | Options used for data-driven rendering. |
| `selected` / `value` | `unknown` | `null` | Controlled selected key. |
| `defaultSelected` / `defaultValue` | `unknown` | `null` | Initial uncontrolled selection. |
| `optionLabel` | `string` | inferred | Field displayed beside each radio button. |
| `optionValue` / `valueField` | `string` | inferred | Field used as the scalar selection and provenance key. |
| `dataKey` | `string` | inferred | Highest-priority stable key field. |
| `name` | `string` | generated | Native radio group name. |
| `onSelectedChange` | `(key, event) => void` | — | Receives the selected key after user or history navigation. |
| `onChange` | `(key, event) => void` | — | Alias callback with the same key. |
| `radioButtonProps` | `object` | `{}` | Props applied to data-driven radio items. |

Aggregate provenance is rendered behind each choice. Opening Temporal view shows the active intervals for all choices, and clicking history restores the scalar group value.

## Web Component events

| Event | `event.detail` |
| --- | --- |
| `selectedChange` | Selected option key. |
| `provenanceChange` | Latest serialized provenance snapshot. |
