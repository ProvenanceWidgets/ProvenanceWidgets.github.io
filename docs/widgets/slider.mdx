# Slider

SW provides a single-value `Singleslider` and a two-handle `Rangeslider`. Both update visually throughout a drag and commit one provenance interaction when the drag ends.

Add a `ProvenanceButton` whose `target` exactly matches the slider `id` to open its Aggregate and Temporal views.

## Single slider

<Tabs groupId="framework">
  <TabItem value="react" label="React">

```tsx
import { useState } from "react";
import { ProvenanceButton, Singleslider } from "provenance-widgets";

export function ScoreSlider() {
  const [score, setScore] = useState(45);

  return (
    <div>
      <ProvenanceButton target="score" />
      <Singleslider
        id="score"
        value={score}
        onChange={setScore}
        onSelectedChange={value => console.log("committed", value)}
        min={0}
        max={100}
        step={1}
        showTicks
        tickStep={10}
        dataLabel="Score"
      />
    </div>
  );
}
```

  </TabItem>
  <TabItem value="web-components" label="Web Components">

```html
<web-provenance-slider
  id="score"
  value="45"
  min="0"
  max="100"
  step="1"
  data-label="Score"
></web-provenance-slider>
```

```js
const slider = document.querySelector("#score");
slider.options = { showTicks: true, tickStep: 10 };

slider.addEventListener("valueChange", event => {
  console.log("live value", event.detail);
});

slider.addEventListener("selectedChange", event => {
  console.log("committed value", event.detail.value);
});
```

</Tabs>

## Range slider

The preferred React value is a tuple: `value={[low, high]}`. The PW-compatible `value={low}` plus `highValue={high}` form is also supported.

<Tabs groupId="framework">
  <TabItem value="react" label="React">

```tsx
import { useState } from "react";
import { ProvenanceButton, Rangeslider } from "provenance-widgets";

export function PriceRange() {
  const [price, setPrice] = useState([75, 180]);

  return (
    <div>
      <ProvenanceButton target="price-range" />
      <Rangeslider
        id="price-range"
        value={price}
        onChange={setPrice}
        onSelectedChange={range => console.log("committed", range)}
        options={{
          floor: 0,
          ceil: 250,
          step: 1,
          showTicks: true,
          tickStep: 25,
        }}
        dataLabel="Price"
      />
    </div>
  );
}
```

  </TabItem>
  <TabItem value="web-components" label="Web Components">

```html
<web-provenance-slider
  id="price-range"
  value="75"
  high-value="180"
  min="0"
  max="250"
  data-label="Price"
></web-provenance-slider>
```

```js
const range = document.querySelector("#price-range");
range.options = { showTicks: true, tickStep: 25 };

range.addEventListener("selectedChange", event => {
  const { value, highValue } = event.detail;
  console.log([value, highValue]);
});
```

## React properties

| Property | Type | Default | Notes |
| --- | --- | --- | --- |
| `value` | `number` or `[number, number]` | — | Controlled value. Use a tuple for a range slider. |
| `defaultValue` | `number` or `[number, number]` | minimum / full range | Initial value for uncontrolled use. |
| `highValue` | `number` | — | PW-compatible upper value for `Rangeslider`. |
| `defaultHighValue` | `number` | — | PW-compatible uncontrolled upper value. |
| `min` / `max` | `number` | `0` / `100` | Numeric domain. |
| `step` | `number` | `1` | Value increment. |
| `options` | `object` | `{}` | PW-compatible `{floor, ceil, step, showTicks, tickStep, ticksArray}`. Direct props take precedence. |
| `showTicks` | `boolean` | `false` | Shows axis ticks below the track. |
| `tickStep` | `number` | `step` | Distance between generated ticks. |
| `ticksArray` | `number[]` | — | Explicit tick values. |
| `onChange` | `(value, event) => void` | — | Fires continuously while a handle moves. |
| `onSelectedChange` | `(value, event) => void` | — | Fires when the drag is committed. |
| `recordExternalChanges` | `boolean` | `true` | Range slider only. Records new controlled values supplied outside the drag interaction. |
| `sliderProps` | `object` | `{}` | Additional props forwarded to the underlying PrimeReact slider. |

Range values are normalized to the configured bounds. A zero-width range is rejected because it cannot be represented by ranged Aggregate provenance.

## Web Component events

| Event | `event.detail` |
| --- | --- |
| `valueChange` | Live single value, or live lower range value. |
| `highValueChange` | Live upper range value. |
| `selectedChange` | `{value}` for a single slider; `{value, highValue}` for a range slider. |
| `provenanceChange` | Latest serialized provenance snapshot. |

Clicking an Aggregate bar or Temporal point restores the corresponding numeric value and calls the public value callbacks.
